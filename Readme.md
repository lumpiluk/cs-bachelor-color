# Color

Interactive 3D visualizations and exercises for the RGB, CMY(K), HSL, and HSV color spaces.

This project is available online at [color.lukas-stratmann.com](https://color.lukas-stratmann.com).

## Building

```bash
deno install
deno task build
```

For development:
Starting a local server and watching changes:
```bash
deno task lume -s  # or `deno task serve`
```
